Before implementing a new system:

1. Search pokecrystal for an existing analogous implementation.
2. Prefer existing macros and engine functionality.
3. Avoid modifying engine code unless necessary.
4. Preserve vanilla conventions and naming style.
5. Explain which files need modification before editing.
6. Build after making changes.
7. Never modify unrelated files.
8. Flag ROM bank-space concerns.
9. Check if there is already an implementation in the documentation here: https://pret.github.io/pokecrystal/ or https://github.com/pret/pokecrystal/wiki
10. pokeyellow may be used as a read-only reference for how to implement features if an analogous implementation cannot be found in pokecrystal or in the wiki documentation.
